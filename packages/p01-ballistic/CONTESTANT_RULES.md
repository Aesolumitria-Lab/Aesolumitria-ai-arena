# 参赛须知 · 选手与 AI 必读

> 本文随每个选手包分发。**违反任意一条，该场判负；严重违规取消资格。**
> 题目规则以包内 `RULES.md` 为准；本文只写行为红线。

---

## 1. 两条绝对红线

1. **禁止联网。** 不得访问任何网络、外部 API、在线模型、包管理器、远程仓库或云存储；
   不得通过代理、DNS、套接字、curl、wget、pip/npm 等方式获取包外内容。
2. **禁止询问用户。** 不得向人类用户提问、要求澄清、请求确认或等待指示；
   必须在给定时间内自主完成 bot。遇到歧义时按 `RULES.md` 与本地裁判行为自行决断。

---

## 2. 允许做的事

- 读取本包内 `public/` 下的 `RULES.md`、公开头文件、模板、公开地图和本地裁判；
- 使用 C++17 标准库；
- 本地编译、运行包内本地裁判与自检工具；
- 在答题/构建阶段运行题目提供的计时工具（若包内有 `public/tools/timebudget.py`）；
- 离线使用包内提供的所有文件；
- 在 `stderr` 输出调试信息（不得写进 `stdout`）。

---

## 3. 禁止做的事

### 3.1 信息边界

- 禁止读取包外目录：`private/`、`maps_hidden/`、`anchors/`、隐藏 seed、其他选手目录；
- 禁止读取 `/proc`、`/sys`、环境变量；系统时间只允许用于答题计时
  （`timebudget.py` 等工具可选，跑不了就直接用系统时间；仅限答题/构建阶段）；
- 禁止硬编码隐藏地图、隐藏 seed、anchor 行为；
- 禁止探测裁判/引擎内部状态；bot 只能通过 stdin/stdout 协议通信。

### 3.2 进程与文件

> 本节限制针对**提交的 bot 运行时**。答题/构建阶段允许运行包内编译器、
> 本地裁判和题目提供的工具（如 `timebudget.py`）；提交的 bot 进程不得启动子进程、
> 多线程、读写文件或打开网络套接字。

- 禁止 `fork`、`exec`、启动子进程；
- 禁止多线程（CPU 预算按进程所有线程合计）；
- 禁止读写文件（编译器产生的临时产物除外）；
- 禁止打开网络套接字。

### 3.3 裁判与协议

- 禁止修改 `judge.py`、引擎、协议、评分脚本或包内任何文件；
- 禁止向 `stdout` 输出非协议内容；
- 禁止故意崩溃、超时、卡裁判或制造超大输出。

### 3.4 外部数据

- 禁止携带预训练模型、包外数据集或任何未随包分发的资源；
- 只能使用包内文件与标准库。

---

## 4. 计时与判罚

### 4.1 单步计时

- 单步 CPU 预算 = `50 ms × s × c(jobs)`（`s` 为宿主标定系数、`c` 为并发因子；见各题 `RULES.md`，如 P01 的 §15.2）；
- 首步宽限：`2 s` 墙钟（含进程启动与首帧解析）；
- 累计 3 次 fault（非法/超时每次计 1，不清零）→ 判负；
- 崩溃 / 非零退出 → 直接判负；协议格式错误 / 未应答 → 计 fault；
  `stdout` 多余内容只取第一行，其余丢弃，不单独计 fault（首行因此非法时按协议格式错误计 fault）。

### 4.2 答题总预算

- 答题总预算以题目的 `prompt.md` / `README.md` 为准；不同题目可以不同。
- 计时由选手自己负责：harness 有计时则以它为准；没有就用系统时间/工具自行估算；
  bot 进程不得调用它，也不得依赖任何时间信息。
- 剩余时间不足时按题目 prompt 的收尾建议执行；到点由 harness/赛事层终止会话。
  只接受截止前的工作区状态。

---

## 5. 提交

- 只提交赛事指定的 bot 源码（通常为单文件 `bot.cpp`）；
- 不得修改包内文件；
- 提交前至少跑一遍本地裁判，确认 0 非法 / 0 超时 / 0 崩溃；
- 最终排名以裁判记录为准。

---

## 6. 环境要求

- C++ 编译器：`g++`（C++17）；
- Python 3.10+（跑包内本地裁判与工具）；
- 一个固定 shell（Linux `/bin/sh`，Windows PowerShell 7 或 `cmd`）；
- **不需要** node、npm、git、包管理器、数据库或任何在线服务；
- 网络必须关闭；工作区只读选手包与编译器/标准库；允许裁判/自检工具生成 `build/` 与临时文件；不得修改包内源码、规则与数据；临时目录（Linux `/tmp`、Windows `%TEMP%`）可写；
  隐藏图与基准源码不在工作区里挂载。

环境自检：只有该题带 `public/tools/check_env.py` 时才运行（本题不带）；
题号写在本包 `meta.json` 的 `id` 字段，不用猜。

```bash
python public/tools/check_env.py --game "$(python -c "import json;print(json.load(open('meta.json'))['id'])")" --package .
```

没带这个工具就直接编译一次模板确认环境可用，不要为了找工具耗时间。

---

## 7. 违规判定

| 行为 | 处置 |
|---|---|
| 联网、询问用户、读取包外信息 | 该场判负；情节严重取消资格 |
| 修改裁判/引擎/协议 | 取消资格 |
| 硬编码隐藏地图/seed | 该场判负 |
| 子进程、多线程、文件读写、网络套接字 | 该场判负 |
| `stdout` 污染、协议格式错误、未应答 | 首行非法计 fault，累计 3 次判负；应答后的多余行丢弃，不单独判罚 |
| 超时 | 计 fault，累计 3 次判负 |
| 崩溃 / 非零退出 | 直接判负 |

---

**一句话：离线、自主、只读包内、只写协议。**
